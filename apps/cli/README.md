# private-notes-cli

Node.js based application for private-notes.

## Usage

Run the script

```js
pnpm start
```

```
      $ [command] [type] <options>

        [command]
          add ............. Create a new [type] (not implemented)
          remove .......... Delete [type] (not implemented)
          update .......... Update [type] (not implemented)
          help ............ Show this help
          version ......... Display the app version
          exit ............ Exit the script

        [type]
          collection ...... Collection of notes
          note ............ A single note
```
